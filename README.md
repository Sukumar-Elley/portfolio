# Sukumar Elley — Portfolio

A responsive personal portfolio for software, data and AI engineering work.

## Stack

- HTML5
- CSS3
- Vanilla JavaScript
- GitHub REST API

## Features

- Dark/light theme
- Responsive navigation
- Scroll reveal animations
- GitHub repository statistics
- Selected project cards loaded from GitHub
- SEO-friendly metadata
- No build step required

## Run locally

Open `index.html` in a browser, or serve the folder with any static HTTP server.

## Deploy

Enable GitHub Pages for the `main` branch. The site will be available at:

`https://sukumar-elley.github.io/portfolio/`
